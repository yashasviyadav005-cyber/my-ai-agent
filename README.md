# AI Study Assistant Agent

An AI-powered Study Assistant built using n8n. It allows students to ask questions through a chat interface and receive AI-generated answers.

### Features

* AI-powered question answering
* Chat-based interaction
* Conversation memory
* Supports study-related topics such as Java, Python, DBMS, DSA and AI
* Built using n8n and Groq GPT-OSS 20B

### Technologies

* n8n
* AI Agent
* Groq
* GPT-OSS 20B
