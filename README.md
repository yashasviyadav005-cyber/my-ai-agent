# 🤖 AI Study Assistant Agent

An AI-powered study assistant built using **n8n** that helps engineering students understand technical concepts through an interactive chat interface.

## 📌 About the Project

The **AI Study Assistant Agent** is designed to provide quick and simple explanations for Computer Science subjects. Students can ask questions related to programming, databases, data structures, web technologies, and AI, and receive AI-generated responses in a student-friendly format.

The agent can also provide **exam-oriented explanations, examples, and simple code** whenever required.

## ✨ Features

* 💬 Interactive AI chat interface
* 🤖 AI-powered question answering
* 🧠 Conversation memory
* 📚 Supports Java, Python, C, DBMS, DSA, HTML/CSS and AI
* 📝 Exam-oriented answers
* 💻 Simple programming examples and code
* 🌐 Built using n8n workflow automation

## ⚙️ Workflow

**Chat Trigger → AI Agent → Groq Chat Model**

Conversation Memory is connected to the AI Agent to maintain the context of the conversation.

## 🛠️ Technologies Used

* **n8n** – Workflow automation
* **AI Agent** – Handles user queries
* **Groq** – AI model provider
* **GPT-OSS 20B** – Language model
* **Conversation Memory** – Maintains chat context
